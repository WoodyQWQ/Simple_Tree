# Simple Tree

Simple Tree 是一款本地优先的树状事项管理 Web 应用。你可以在大纲中组织无限层级的事项，也可以在可编辑图谱中查看结构、调整位置和重新关联节点。数据默认保存在浏览器本机，无需注册账号或部署后端。

## 功能特性

- **大纲管理**：新建、重命名、折叠展开、拖拽移动、同级排序和删除子树。
- **完成与进度**：完成叶子事项、批量完成子树，并自动汇总容器节点的完成进度。
- **快速录入**：添加事项时手动选择父节点；可选 AI 自动关联最多提供 3 个建议，确认后才会生效。
- **可编辑图谱**：基于 Canvas 2D 展示整棵树，支持平移、缩放、适应窗口、自动布局、图内新增、节点位置调整及拖到另一节点重新关联。
- **搜索与筛选**：按标题搜索，并按完成状态、优先级和截止日筛选。
- **事项详情**：编辑备注、优先级、截止日，以及添加、打开和移除附件。
- **撤销与重做**：支持当前会话内的数据操作撤销与重做。
- **本地数据管理**：IndexedDB 持久化、JSON 导入导出、导入前自动备份及最近 3 份备份恢复。
- **外观设置**：浅色、深色、跟随系统主题，以及预设或自定义主题色。
- **多标签页同步**：同一浏览器中的多个标签页会在数据变更后自动刷新。

## 本地运行

### 环境要求

- Node.js 22.12 或更高版本（推荐）
- npm

### 启动步骤

```bash
git clone https://github.com/WoodyQWQ/Simple_Tree.git
cd Simple_Tree
npm install
npm run dev
```

开发服务器默认运行在 <http://localhost:5183>。

### 可用命令

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 执行 TypeScript 类型检查并构建生产版本 |
| `npm run preview` | 预览生产构建 |
| `npm test` | 运行 Vitest 测试 |

生产构建输出到 `dist/` 目录。

## 基本使用

1. **添加事项**：点击工具栏的“快速添加”，输入标题并选择父节点；也可以在大纲或图谱中直接新增。
2. **组织事项**：在大纲中拖拽节点调整层级或顺序；在图谱中拖动节点调整位置，拖到另一节点可重新关联。
3. **完善详情**：选中节点后，在右侧详情面板编辑备注、优先级、截止日和附件。
4. **查找事项**：使用顶部搜索框，或组合状态、优先级和截止日筛选条件。
5. **管理数据**：打开“设置与数据”，导出 JSON、导入数据或恢复最近备份。

macOS 使用 `⌘`，Windows 和 Linux 使用 `Ctrl`。

| 操作 | 快捷键 |
| --- | --- |
| 快速添加 | `⌘/Ctrl + Shift + N` |
| 聚焦搜索 | `⌘/Ctrl + K` |

## AI 自动关联（可选）

AI 功能默认关闭。启用前需要在“设置与数据”中配置：

- OpenAI 兼容接口地址，例如 `https://api.openai.com/v1`
- 模型名称
- 自己的 API 密钥
- 可选代理地址，用于解决浏览器跨域限制

启用后，应用会将**新事项标题、本地筛选出的候选节点标题与父路径**发送到你配置的第三方模型服务，不会发送节点备注、完成状态或时间戳。AI 仅提供父节点建议，不会直接修改数据。

API 密钥只保存在本机 IndexedDB 中，不包含在 JSON 导出或备份中。使用第三方模型服务时，请同时遵守对应服务商的隐私政策。

## 数据存储与备份

- 节点、设置、图谱手动坐标、附件元数据和备份保存在 IndexedDB 数据库 `simple-tree` 中。
- 附件内容使用浏览器的 OPFS（Origin Private File System）保存，需要浏览器支持。
- JSON 导出仅包含节点数据，**不包含附件、AI 配置、API 密钥或图谱手动坐标**。
- 覆盖导入和恢复备份前会自动创建快照，最多保留最近 3 份备份。
- 如果浏览器本地存储不可用，应用会进入临时内存模式，此时更改不会被保存，界面会显示警告。
- 清除浏览器站点数据可能删除应用数据，建议定期导出 JSON，并单独备份重要附件。
